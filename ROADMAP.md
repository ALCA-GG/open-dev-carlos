# Roadmap

OpenDev avanza por fases. El orden importa: no se añade contenido avanzado hasta que los fundamentos estén suficientemente cubiertos.

## Fase 1 — Fundación

- [x] Configuración del repositorio.
- [x] Estándares de contribución.
- [x] Guía de instalación de Java.
- [x] Guía de Git y GitHub.
- [x] Primeros ejercicios.

## Fase 2 — Fundamentos

- [x] Variables y tipos.
- [x] Operadores.
- [x] Control de flujo.
- [x] Bucles.
- [x] Métodos.
- [ ] Ampliar ejercicios de cada tema.
- [ ] Añadir soluciones explicadas.

## Fase 3 — Java intermedio

- [x] Arrays y cadenas.
- [x] Programación orientada a objetos.
- [x] Excepciones.
- [x] Colecciones.
- [ ] Ejercicios integradores por módulo.
- [ ] Retos opcionales.

## Fase 4 — Desarrollo práctico

- [x] Estructura de proyectos.
- [x] Tests con JUnit 5.
- [x] Guía de revisión de código.
- [ ] Proyectos guiados de dificultad creciente.
- [ ] Introducción al diseño de software.

## Fase 5 — Expansión de la comunidad

- [ ] Incorporar maintainers.
- [ ] Organizar eventos y sesiones de revisión.
- [ ] Ampliar recursos externos.
- [ ] Publicar la versión 1.0.0 cuando la estructura sea estable.

## Cómo proponer cambios

Abre un issue o un Pull Request siguiendo [`CONTRIBUTING.md`](CONTRIBUTING.md). Las propuestas deben explicar el valor educativo y encajar en la fase actual.
