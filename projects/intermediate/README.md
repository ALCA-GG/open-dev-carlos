# Proyectos de nivel intermedio

Proyectos que combinan clases, colecciones, excepciones y tests.

## Ideas propuestas

### Gestor de contactos

- Contactos con nombre, correo y teléfono.
- Evitar correos duplicados.
- Buscar, actualizar y eliminar.
- Persistencia opcional en un archivo de texto.

Conceptos: POO, `Map`, excepciones, entrada/salida.

### Gestor de tareas

- Tareas con título, prioridad y estado.
- Filtrar por estado.
- Marcar como completadas.
- Historial de cambios.

Conceptos: POO, `List`, `enum`, tests.

### Sistema de biblioteca

- Libros, usuarios y préstamos.
- Validar disponibilidad.
- Calcular fechas de devolución.
- Registrar devoluciones.

Conceptos: POO, `LocalDate`, colecciones, validación.

### Inventario

- Productos con precio y stock.
- Añadir stock y registrar ventas.
- Alertas de stock mínimo.

Conceptos: `Map`, encapsulación, tests.

## Requisitos

- README con objetivo, diseño y comandos.
- Tests para las reglas de negocio.
- Manejo de errores con mensajes claros.
- Sin dependencias externas salvo justificación.
