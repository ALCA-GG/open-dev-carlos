# Proyectos avanzados

Proyectos para practicar diseño de software, persistencia y organización de código. Siguen siendo educativos: evita frameworks y servicios externos innecesarios.

## Ideas propuestas

### Sistema de gestión de una pequeña tienda

- Catálogo, clientes, ventas e inventario.
- Separación entre dominio, persistencia y consola.
- Tests de las reglas de negocio.
- Persistencia en archivos JSON o CSV sin dependencias externas si es posible.

### Planificador de estudio

- Materias, sesiones y objetivos.
- Cálculo de tiempo restante.
- Reportes por semana.
- Persistencia local.

### Motor de reglas simple

- Reglas configurables para validar datos.
- Composición de condiciones.
- Tests exhaustivos.
- Documentación del diseño.

## Criterios

- Diseño explicado en el README.
- Separación de responsabilidades.
- Tests significativos.
- Manejo de errores y datos inválidos.
- Sin dependencias injustificadas.
- Documentación de las decisiones importantes.

## Antes de empezar

Estos proyectos requieren haber completado la ruta inicial. Si es tu primer proyecto grande, empieza por [`../intermediate/`](../intermediate/).

## Contribuir

Abre un issue con el diseño propuesto antes de implementar. El Owner revisará el alcance para mantener el proyecto educativo y mantenible.
