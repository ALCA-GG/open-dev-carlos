# Proyectos para principiantes

Proyectos que usan variables, condicionales, bucles y métodos. Todavía no requieren programación orientada a objetos.

## Ideas propuestas

### Calculadora de consola

- Suma, resta, multiplicación y división.
- Validación de división entre cero.
- Menú repetido hasta que el usuario salga.

Conceptos: métodos, `switch`, bucles, excepciones básicas.

### Conversor de unidades

- Celsius a Fahrenheit y viceversa.
- Metros a kilómetros.
- Menú de opciones.

Conceptos: variables, operadores, condicionales.

### Generador de tablas de multiplicar

- Pide un número y muestra su tabla.
- Permite repetir con otro número.

Conceptos: bucles, entrada por consola.

### Juego de adivinanza

- Número secreto aleatorio.
- Pistas de mayor o menor.
- Contador de intentos.

Conceptos: `Random`, bucles, condicionales.

## Cómo empezar

1. Elige una idea.
2. Abre un issue con el nombre del proyecto.
3. Crea la carpeta `projects/beginner/<nombre>/`.
4. Añade un README con el enunciado y los comandos.
5. Implementa y prueba.
6. Abre un Pull Request.

No copies una solución completa de internet. Si te inspiras en un recurso, cítalo.
