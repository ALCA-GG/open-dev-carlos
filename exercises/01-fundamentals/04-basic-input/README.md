# Ejercicio: Entrada básica

## Dificultad

Principiante

## Objetivos de aprendizaje

Leer datos del usuario con `Scanner` y construir un mensaje con ellos.

## Descripción

Pide el nombre al usuario y muestra un saludo personalizado.

## Requisitos

- Usar `Scanner` para leer una línea.
- Construir el saludo en un método separado.
- Mostrar el resultado por consola.

## Ejemplo de ejecución

```text
¿Cómo te llamas? Ana
Hola, Ana!
```

## Pistas

`scanner.nextLine()` lee una línea completa. Para probar la lógica sin entrada interactiva, separa la construcción del saludo en un método.

## Criterios de aceptación

- El programa lee el nombre.
- El saludo tiene el formato esperado.
- El método que construye el saludo se puede probar de forma aislada.

## Reto adicional

Valida que el nombre no esté vacío y muestra un mensaje de error si lo está.
