# Ejercicio: Variables

## Dificultad

Principiante

## Objetivos de aprendizaje

Declarar variables, asignar valores e intercambiar el contenido de dos variables.

## Descripción

Crea dos variables enteras, `a = 5` y `b = 10`. Muestra sus valores, intercámbialos y vuelve a mostrarlos.

## Requisitos

- Usar dos variables enteras.
- Intercambiar los valores sin escribir los números de nuevo a mano.
- Mostrar el estado antes y después del intercambio.

## Salida esperada

```text
Antes: a=5, b=10
Después: a=10, b=5
```

## Pistas

Necesitas una tercera variable temporal para guardar uno de los valores.

## Criterios de aceptación

- La salida coincide con la esperada.
- El intercambio se realiza con variables, no imprimiendo valores literales distintos.
- El código es legible.

## Reto adicional

Realiza el intercambio sin usar una tercera variable. Investiga el operador XOR o la suma y resta, y explica las ventajas y desventajas.
