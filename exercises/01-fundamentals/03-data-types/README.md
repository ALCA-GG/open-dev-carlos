# Ejercicio: Tipos de datos

## Dificultad

Principiante

## Objetivos de aprendizaje

Usar tipos numéricos y calcular un promedio con decimales.

## Descripción

Calcula el promedio de tres notas: `7.5`, `8.0` y `6.5`. Muestra el resultado con un decimal.

## Requisitos

- Usar variables de tipo `double`.
- Calcular el promedio con una operación aritmética.
- Mostrar el resultado.

## Salida esperada

```text
Promedio: 7.333333333333333
```

## Pistas

Si divides entre un número entero, Java puede realizar una división entera. Asegúrate de que al menos uno de los operandos sea `double`.

## Criterios de aceptación

- El resultado es correcto.
- Se usan variables para las notas.
- El código compila y es legible.

## Reto adicional

Muestra el promedio con dos decimales usando `System.out.printf` y explica qué hace `%n`.
