# Ejercicio: Hello World

## Dificultad

Principiante

## Objetivos de aprendizaje

Entender cómo crear y ejecutar un programa Java básico, y cómo imprimir texto por consola.

## Descripción

Crea un programa que muestre el mensaje `Hello, World!` en la consola.

## Requisitos

- Crear una clase llamada `Main`.
- Implementar el método `main`.
- Imprimir exactamente el mensaje solicitado.

## Salida esperada

```text
Hello, World!
```

## Pistas

Usa `System.out.println()`.

## Criterios de aceptación

- El programa compila.
- La salida coincide exactamente con la esperada.
- El código sigue las convenciones de Java.

## Reto adicional

Modifica el programa para mostrar tu nombre en una segunda línea.
