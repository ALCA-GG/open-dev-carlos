# 01 — Fundamentos

Ejercicios para dar los primeros pasos con Java.

## Ejercicios disponibles

| Ejercicio                           | Objetivo                                    | Dificultad   |
| ----------------------------------- | ------------------------------------------- | ------------ |
| [`01-hello-world`](01-hello-world/) | Imprimir por consola y ejecutar un programa | Principiante |
| [`02-variables`](02-variables/)     | Declarar variables e intercambiar valores   | Principiante |
| [`03-data-types`](03-data-types/)   | Usar tipos numéricos y calcular un promedio | Principiante |
| [`04-basic-input`](04-basic-input/) | Leer datos con `Scanner`                    | Principiante |

## Orden recomendado

1. `01-hello-world`
2. `02-variables`
3. `03-data-types`
4. `04-basic-input`

## Antes de empezar

Lee el [módulo 01](../../docs/learning-path/01-java-fundamentals.md) y el [módulo 02](../../docs/learning-path/02-variables-and-types.md).
