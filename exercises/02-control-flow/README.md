# 02 — Control de flujo

Ejercicios para practicar decisiones con `if`, `else`, `else if` y `switch`.

## Estado

Esta categoría aún no tiene ejercicios publicados. Es una oportunidad ideal para una primera contribución.

## Temas previstos

- Clasificar una nota.
- Comprobar si un año es bisiesto.
- Calcular el mayor de tres números.
- Asignar una tarifa según la edad.
- Usar `switch` para menús sencillos.
