# Documentación de OpenDev

Este directorio reúne el material necesario para aprender y contribuir.

## Contenido

- [`getting-started/`](getting-started/): instalación y configuración del entorno.
- [`learning-path/`](learning-path/): ruta progresiva de Java, desde cero.
- [`guides/`](guides/): Git, GitHub, Pull Requests, revisión y estilo.
- [`governance/`](governance/): roles, decisiones, etiquetas, configuración de GitHub y política de contribución.
