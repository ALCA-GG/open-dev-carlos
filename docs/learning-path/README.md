# Ruta de aprendizaje

Esta ruta está diseñada para personas que nunca han programado. Avanza en orden, practica con los ejercicios de cada módulo y no tengas miedo de repetir.

## Cómo usar la ruta

1. Lee el módulo.
2. Copia y ejecuta los ejemplos.
3. Resuelve los ejercicios de [`exercises/`](../../exercises/).
4. Intenta el reto adicional.
5. Si algo no funciona, lee el error con calma y consulta [`SUPPORT.md`](../../SUPPORT.md).

## Requisitos

- Haber completado [`../getting-started/installation.md`](../getting-started/installation.md).
- Tener Java 21 y el Maven Wrapper funcionando.

## Filosofía

- **Practica más de lo que lees.** Programar se aprende escribiendo y corrigiendo errores.
- **Avanza sin prisa.** No pasa nada si repites un módulo.
- **Pregunta.** Nadie nace sabiendo qué es una variable.
- **No copies sin entender.** Intenta explicar cada línea con tus palabras.
