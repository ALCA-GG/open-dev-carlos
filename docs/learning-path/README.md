# Ruta de aprendizaje

Esta ruta está diseñada para personas que nunca han programado. Avanza en orden, lee con calma y practica con los ejemplos de cada módulo.

## Cómo usar la ruta

1. Lee el módulo.
2. Copia y ejecuta los ejemplos.
3. Modifícalos para experimentar.
4. Comprueba que entiendes cada línea antes de avanzar.
5. Si algo no funciona, lee el error con calma y consulta [`SUPPORT.md`](../../SUPPORT.md).

Los ejercicios se publicarán de forma progresiva, uno a uno, a medida que el alumnado avance. Esta versión inicial no incluye ejercicios ni soluciones.

## Requisitos

- Haber completado [`../getting-started/installation.md`](../getting-started/installation.md).
- Tener Java 25 y el Maven Wrapper funcionando.

## Filosofía

- **Practica más de lo que lees.** Programar se aprende escribiendo y corrigiendo errores.
- **Avanza sin prisa.** No pasa nada si repites un módulo.
- **Pregunta.** Nadie nace sabiendo qué es una variable.
- **No copies sin entender.** Intenta explicar cada línea con tus palabras.
