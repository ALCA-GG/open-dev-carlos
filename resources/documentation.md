# Documentación oficial

La documentación oficial es la fuente más fiable. Estas referencias son útiles durante toda la ruta.

## Java

- [Java SE Documentation](https://docs.oracle.com/en/java/javase/25/): documentación de Java 25.
- [Java API Specification](https://docs.oracle.com/en/java/javase/25/docs/api/): referencia de clases y métodos.
- [Dev.java](https://dev.java/): tutoriales oficiales.
- [Java Language Specification](https://docs.oracle.com/javase/specs/): especificación del lenguaje.

## Herramientas

- [Apache Maven](https://maven.apache.org/guides/): guías de Maven.
- [Maven Wrapper](https://maven.apache.org/wrapper/): documentación del wrapper.
- [JUnit 5 User Guide](https://junit.org/junit5/docs/current/user-guide/): guía de JUnit.
- [Checkstyle](https://checkstyle.org/): reglas y configuración.
- [Spotless](https://github.com/diffplug/spotless): formateo de código.
- [IntelliJ IDEA](https://www.jetbrains.com/help/idea/): documentación del IDE recomendado.
- [Apache NetBeans](https://netbeans.apache.org/tutorials/): tutoriales del IDE recomendado.

## Git y GitHub

- [Pro Git](https://git-scm.com/book/es/v2): libro oficial en español.
- [GitHub Docs](https://docs.github.com/es): documentación de GitHub.
- [Conventional Commits](https://www.conventionalcommits.org/es/v1.0.0/): especificación de commits.
- [Semantic Versioning](https://semver.org/lang/es/): versionado semántico.

## Cómo leer la documentación

- Busca la clase o método que necesitas.
- Lee la firma, los parámetros y las excepciones.
- Revisa los ejemplos.
- Comprueba la versión de Java.
- Prueba en un programa pequeño antes de integrarlo.
