# Enlaces útiles

Recursos gratuitos para practicar y resolver dudas.

## Práctica

- [Exercism — Java](https://exercism.org/tracks/java): ejercicios con mentoría.
- [Codewars](https://www.codewars.com/): retos cortos por niveles.
- [Advent of Code](https://adventofcode.com/): retos anuales (a partir de diciembre).
- [HackerRank — Java](https://www.hackerrank.com/domains/java): ejercicios guiados.

## Cursos y tutoriales

- [MOOC.fi — Programming with Java](https://java-programming.mooc.fi/): curso gratuito y completo.
- [Codecademy — Learn Java](https://www.codecademy.com/learn/learn-java): curso interactivo (parte gratuita).
- [Baeldung Java](https://www.baeldung.com/java-tutorial): artículos y ejemplos.

## Comunidad

- [GitHub Discussions de OpenDev](https://github.com/carlosgarcia-tech/open-dev/discussions): preguntas y ayuda.
- [Stack Overflow en español](https://es.stackoverflow.com/): preguntas técnicas.
- [r/learnjava](https://www.reddit.com/r/learnjava/): comunidad de aprendizaje.

## Herramientas

- [JDoodle](https://www.jdoodle.com/online-java-compiler): compilador online.
- [regex101](https://regex101.com/): probar expresiones regulares.
- [Mermaid Live Editor](https://mermaid.live/): diagramas en Markdown.

## Aviso

OpenDev no controla el contenido de sitios externos. Verifica la licencia, la versión de Java y la calidad antes de usar un recurso. No se aceptan enlaces afiliados ni contenido pirateado.
