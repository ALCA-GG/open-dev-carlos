# Recursos

Material complementario para seguir aprendiendo. Los enlaces externos pertenecen a sus autores y pueden cambiar con el tiempo.

## Contenido

- [`books.md`](books.md): libros recomendados.
- [`documentation.md`](documentation.md): documentación oficial.
- [`useful-links.md`](useful-links.md): cursos, prácticas y comunidades.

## Cómo usar los recursos

1. Prioriza la documentación oficial.
2. Practica con los ejercicios del repositorio.
3. Usa los libros como apoyo, no como sustituto de escribir código.
4. Verifica que el recurso esté actualizado para Java 21.

## Sugerir un recurso

Abre un issue o un Pull Request con:

- Título y enlace.
- Autor o institución.
- Por qué es útil para principiantes.
- Si es gratuito o de pago.
- Idioma.

No se aceptan enlaces afiliados, publicidad ni contenido pirateado.
