# Soporte

OpenDev es un proyecto educativo mantenido por voluntarios. No hay un servicio de soporte con horarios garantizados, pero intentaremos ayudar dentro de lo posible.

## Antes de preguntar

1. Lee la documentación de [`docs/`](docs/).
2. Revisa los issues abiertos y cerrados.
3. Comprueba que usas Java 21 y la versión de Node.js indicada en `.nvmrc`.
4. Ejecuta `./mvnw clean verify` y `npm run validate` para descartar problemas de configuración.

## Dónde pedir ayuda

| Tipo de consulta                            | Canal recomendado                                    |
| ------------------------------------------- | ---------------------------------------------------- |
| Dudas de programación o de Java             | GitHub Discussions                                   |
| Error en la documentación                   | Issue con la plantilla de documentación              |
| Error en un ejercicio o en la configuración | Issue con la plantilla de bug                        |
| Duda sobre cómo contribuir                  | Comentario en el issue correspondiente o Discussions |
| Vulnerabilidad de seguridad                 | Reporte privado según [`SECURITY.md`](SECURITY.md)   |

## Qué incluir en una pregunta

- Qué intentas conseguir.
- Qué has probado.
- Qué esperabas que ocurriera.
- Qué ocurrió realmente.
- Mensajes de error completos.
- Versión de Java (`java -version`), sistema operativo y versión de Node.js (`node --version`).

## Lo que no ofrecemos

- Soporte comercial.
- Resolución de tareas académicas completas sin participación de la persona que aprende.
- Tiempos de respuesta garantizados.
- Ayuda con código ajeno al repositorio.

## Código de Conducta

Todas las interacciones deben respetar el [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). La paciencia y la amabilidad son especialmente importantes en una comunidad de aprendizaje.
