# Soluciones

Las soluciones viven separadas de los enunciados para no arruinar el aprendizaje. Cada solución incluye una explicación del razonamiento, no solo el código.

## Soluciones disponibles

| Ejercicio   | Solución                                                            |
| ----------- | ------------------------------------------------------------------- |
| Hello World | [`01-fundamentals/01-hello-world`](01-fundamentals/01-hello-world/) |

## Reglas

- Intenta resolver el ejercicio antes de leer la solución.
- Compara tu enfoque con la explicación.
- Una solución no es la única respuesta correcta.
- Si encuentras una solución mejor, propón una mejora mediante un Pull Request.

## Contribuir con una solución

1. Abre un issue indicando el ejercicio.
2. Crea la carpeta en `solutions/` con la misma ruta relativa que el ejercicio.
3. Incluye un README con la explicación.
4. Añade el código siguiendo las convenciones.
5. Ejecuta las validaciones y abre un Pull Request.
